How a chapter works

Play comes first. The reading, the talking and the code all build on what you found in the game.

  1. Play

    Start with the game. It opens with the plain problem and lets you get properly stuck before it helps. The exploration guide gives you things to notice as you go.

  2. Talk

    Bring what you found to the discussion questions, using the vocabulary the game gave you once you had earned it.

  3. Build

    Do the same moves with the scaffolding gone: code the algorithm, and work it through on paper.

  4. Present

    Explain an algorithm to people who have not met it yet. If you can teach it, you own it.
